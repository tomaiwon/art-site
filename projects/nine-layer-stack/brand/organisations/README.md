# Organisation logo assets

These assets identify organisations in the Digital Age Atlas company view.
They are stored locally so the research interface does not depend on a remote
image service at runtime. Display code preserves each asset's aspect ratio and
colour and provides a text fallback when an organisation has no logo.

Company names, logos and trademarks remain the property of their respective
owners. Their appearance here is for identification in an independent research
interface and does not imply endorsement or partnership.

The assets explicitly labelled as locally authored are simple identification
marks created in-repo so the company view has a recognisable mark without a
runtime download. They approximate the respective brand style but are not
official artwork; replace them with each owner's official asset before any
production or marketing use.
