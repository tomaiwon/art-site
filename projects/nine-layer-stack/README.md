# 九层堆栈图谱

Static export of the 《东亚制造》背景图谱 homepage, generated by
`scripts/build-public-atlas.mjs` in the private Atlas repository.

- Only verified and partially verified company relationships are
  included; candidate, historical and pending-review records and their
  otherwise unreferenced evidence are removed at build time.
- No server routes: stylised background generation is not available.
- The display face is a glyph subset of 字悦影印宋, used on this site
  with the owner's confirmed website permission. It is not licensed for
  redistribution.
- Company marks identify organisations only; some are simplified
  identification artwork rather than official brand files.
