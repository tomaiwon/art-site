# 海报倒推（只读版）

胶片手记里的 REVERSE（`#/reverse`）。这个文件夹是 `poster-reverse-studio/tools/showcase.py export` 生成的，别手改：
放哪些海报、配什么话改 `poster-reverse-studio/showcase/showcase.json`，页面改 `poster-reverse-studio/reverse/fj.js`，再导出。

- `fj.js`、`fj.css`：跟本机工作台里的是同一份，`window.RV_PUBLIC` 打开只读（不能放海报、挑照片、改）
- `data/index.json`：首页的海报列表
- `inbox/<时间>/`：`project.json`（只有分析：框、字、颜色、阅读路径、锚、为什么好看……）、`ref.jpg`（原作，出处写在图注里）、我们的当前版
