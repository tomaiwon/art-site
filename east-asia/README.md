# East Asia Manufacturing cover

Published presentation only: the existing ink globe and falling traditional glyphs.
The desktop entry continues to ../effects/; mobile omits the two lower-left elements.
No news archive, private Atlas company dataset, collector, API or scheduler is included.
The original NEWS, effects game case and effects/studio are unchanged.

The owner confirmed website permission for the selected Yinying and GuYin fonts
on 2026-09-09. This is project-specific permission, not a grant to redistribute fonts.
Unselected trial fonts and the full source fonts are not included.

Built from the canonical Atlas design/public-cover and scripts/build-public-cover.mjs,
reusing InteractiveGlobe, the print pass, trails, fall model and layout bridge.
No replacement renderer or public backend is introduced.
