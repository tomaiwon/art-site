AI Video Workflow

生成视频制作 / 计划项目

计划制作一个30–60秒的小型AI视频案例，重点记录镜头如何被设计、生成、修改和完成，而不止展示最终画面。

项目类型
Generative Video / Visual Production
拟承担角色
视觉开发、镜头设计与后期制作
时间与状态
计划阶段 / 制作时间待定
计划产出
30–60秒视频 + 制作过程记录
尚未完成成片

本页记录下一阶段的实践方向。制作完成后，将补充真实镜头、过程对比、失败案例与生成成本。

准备验证的问题01 / QUESTION

如何在多个生成镜头之间控制角色、场景与风格的一致性？当一个局部出现问题时，如何通过局部修改或人工后期完成修正，减少整段重新生成？

计划把已有的影像制作经验带入AI视频生产，建立从参考到最终输出的可复盘流程。

计划制作流程02 / PROPOSED PROCESS

  1. 01 / REFERENCE

    参考与分镜

    明确视觉参考、叙事节奏和分镜，先确定画面需要完成什么。

  2. 02 / SHOT DESIGN

    镜头设计

    拆解构图、运动、景别和镜头衔接，建立可执行的生成任务。

  3. 03 / GENERATION

    生成与筛选

    记录生成参数、候选版本与失败情况，保留可比较的制作记录。

  4. 04 / CONSISTENCY

    一致性控制

    比较角色、场景、色彩与运动的一致性，验证局部修正方法。

  5. 05 / COMPOSITING

    合成与剪辑

    通过AE合成、人工后期和剪辑处理镜头衔接与局部问题。

  6. 06 / FINAL OUTPUT

    声音与成片

    完成声音、节奏与输出，整理30–60秒案例及制作复盘。

将记录什么03 / DOCUMENTATION

  • 参考、分镜与最终镜头之间的对应关系。
  • 一致性问题、失败版本与具体修正步骤。
  • 局部修改和完整重新生成的取舍。
  • 实际生成次数、成本与人工后期投入。
  • 从原始生成结果到最终成片的前后对比。

所有过程与结果将在实际制作后补充。
