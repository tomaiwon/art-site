# Yi Huang 求职作品集

平行入口：`https://yihuang.art/career/`。原艺术网站及页面保持不变。

本目录沿用原网站的静态 HTML 和 GitHub Pages 发布方式，无额外构建依赖。

- `index.html`：定位、代表项目、教育、分组能力与联系方式。
- `as-fables-go-by.html`：24分钟影像的求职案例、按需加载的既有 Vimeo 播放器与原艺术页入口。
- `ai-content-workflow.html`：人工在环内容工作流及真实图文成品。
- `ai-video-workflow.html`：计划中的30–60秒案例，尚未完成；新增真实作品后再更新状态。
- `reading.css`：从现有「见闻与沉思录 / Studio」界面继承的纸色、字体、页头与目录菜单样式。
- `style.css`、`site.js`：求职页面的阅读排版、目录交互、复制邮箱与按需播放器，仅作用于本目录。
- `assets/`：来自原作品的网页压缩图、现有图文成品与新入口图标。

内容依据：用户提供的《求职.docx》、原站公开履历和作品、已有东亚制造图文流程及成品。项目时长、职责、教育与职业方向以本次求职文档为准。未编造效率、用户或传播数据。

视觉基础为原站「见闻与沉思录 / Studio」：纸色底、宋体正文、细线分节、双层页头、全屏目录与连续阅读布局。复用其 Studio 标志、Source Serif 4 与 DM Mono 字体；求职页中文使用单独生成的思源宋体子集 `assets/reading-song-career.woff2`，覆盖当前 HTML 与脚本文案。字体来源、版本及散列记录在 `assets/font-manifest.json`，授权见 `assets/SourceHanSerif-OFL.txt`。后续新增中文需重新检查字形覆盖。

原站页面及资源不作修改。Vimeo 播放器仅在读者点击后加载，外部观看链接常驻。目录支持键盘 Escape 关闭、焦点返回与页内栏目跳转。

本地预览：从网站仓库根目录启动静态服务器，打开 `/career/`。不要只服务本目录，否则父级原站资源和字体无法解析。

发布前检查：内部链接与图片、手机和桌面布局、复制邮箱、研究背景展开、播放器加载、原站无修改。
